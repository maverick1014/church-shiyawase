## 已知的缺口 / 欠账

- **浏览器套件不在 CI 里**（`ui-e2e.yml` 只手动 dispatch）。挡在坏改动和线上站点之间的只有推送的人（G0）。

  真正的修复是不会暂停的套餐；退而求其次是把 cron 改成每天（本仓库公开，Actions 分钟免费）。
